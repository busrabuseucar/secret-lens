# CV'ye ekleme taslağı

**SecretLens — Yerel Gizli Değer Tarayıcısı**  
TypeScript, Node.js, Web Workers, GitHub Actions

[GitHub](https://github.com/busrabuseucar/secret-lens) · [Canlı demo](https://secret-lens-buse.sleek-brush-8818.chatgpt.site)

> AI desteğiyle; kaynak dosyalarında beş sezgisel kuralla olası gizli değerleri tespit eden, tarayıcı ve CLI üzerinden çalışan bir araç geliştirdim. Ham değerleri ve dosya adlarını dışa aktarmayan JSON raporları, girdi sınırları ve otomatik regresyon testleri ekledim.

Bu metni projeyi çalıştırıp veri akışını ve kuralları açıklayabildiğinde kullan. Otomatik testlerin sonuçları [GitHub Actions](https://github.com/busrabuseucar/secret-lens/actions/workflows/ci.yml) sayfasında izlenebilir.

## Daha kısa sürüm

> **SecretLens:** TypeScript ile yerel dosya tarama, maskeli JSON raporlama ve ortak tarayıcı/CLI motoru; AI destekli kişisel güvenlik projesi.

GitHub ve herkese açık demo bağlantılarını proje başlığının yanına ekle. İş deneyimi yerine **Projeler** bölümünde kullan. Gerçek sistemlerde önlenen olay, doğruluk yüzdesi veya kullanıcı sayısı gibi ölçülmemiş sonuçlar ekleme.

## İngilizce sürüm

> **SecretLens — Local Secret Scanner:** Built an AI-assisted TypeScript browser and Node.js CLI tool to flag potential credentials using five heuristic rules. Added fully masked JSON reports, bounded input processing, and automated regression tests.
